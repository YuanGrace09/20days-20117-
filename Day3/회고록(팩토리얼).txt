4. 놓치기 쉬운 엣지 케이스 (Edge Cases) - (AI 지적문🟢)
문제점1: 수학적으로 0! = 1입니다. 하지만 ReturnBack(0)을 호출하면 if (i <= 2) 조건에 걸려 1을 반환하긴 하나, 로직상의 오점이 존재합니다.실제 버그: ReturnBack 재귀 함수는 i <= 2일 때 무조건 1을 리턴하도록 되어 있어, 음수나 $0$을 넣었을 때도 무조건 $1$이 출력되는 문제가 발생합니다.
  -해결법: 팩토리얼의 기본 기저 조건(Base Case)을 0! = 1, 1! = 1로 명확히 분리해야 합니다.

문제점2: 자바의 int 데이터 타입은 최대 2,147,483,647까지만 표현할 수 있습니다.
실제 버그: 13!팩토리얼만 되어도 6,227,020,800으로 int 범위를 넘어섭니다. 
따라서 13팩토리얼 이상의 값을 입력하면 마이너스(-) 값이 출력되거나 엉뚱한 결과가 나오게 됩니다.
  -해결법: 반환 타입을 long으로 변경(최대 20팩토리얼까지 가능)하거나, 더 큰 수를 다룰 때는 BigInteger 클래스를 사용해야 합니다.

4. 코드에서 비효율적이거나 개선이 필요한 부분 - (AI 지적문🟢)
문제1: if (i <= 2) return 1; 구문 때문에 2 팩토리얼(2!)의 결과가 1로 잘못 계산됩니다. (2! = 2 * 1 = 2 이어야 함)
  -개선법: 조건식을 i <= 1로 수정해야 2! = 2, 1! = 1, 0! = 1이 정확하게 계산됩니다.

문제2: main 메소드 안에서 결과를 출력하는 System.out.println 구문이 if문과 else if문에 중복되어 작성되어 있습니다. 또한, 사용자가 1이나 2가 아닌 다른 번호(예: 3, 99)를 입력하면 아무런 안내 없이 프로그램이 끝납니다.
  -개선법: 선택지에 대한 else 예외 구문을 추가하고, 출력 코드는 하단에 하나로 합쳐서 작성합니다.


재귀 함수 코드 수정:

```public static long ReturnBack(int i) {    
    if (i <= 1) { // 0!과 1!은 모두 1
        return 1;
    }
    return i * ReturnBack(i - 1);
}
